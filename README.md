# ISKRA · ИСКРА — гибридный сюрреалистичный прототип

**Рабочая версия:** 0.3 · **Жанр:** атмосферное приключение / сюрреалистичная головоломка  
**Формат:** Явь (объёмный 3D) ↔ Навь (плоский 2D) → Правь (пространство памяти в финале)

## Концепция

Ты просыпаешься на станции-ковчеге «Русь-7» в образе маленького огня. Станция помнит тебя, но ты не помнишь себя. Сварог-ИИ утверждает, что ты — недостающая искра его души. Домовой ведёт тебя через две версии одной реальности:

- **Явь** — материальный, объёмный мир: металл, холод, физические препятствия.
- **Навь** — плоская изнанка мира: символы, тени, скрытые проходы и фрагменты памяти.
- **Правь** — будущая третья форма пространства, в которой геометрия будет подчиняться воспоминаниям.

Главный художественный принцип: переход в 2D — не просто смена камеры. Это способ увидеть, что предметы и места означают на самом деле. В идеале стена в Яви может стать дверью в Нави, а найденное воспоминание — изменить обе версии комнаты.

## Что уже есть в прототипе

- Three.js-сцена Яви и Canvas 2D-сцена Нави.
- Переходы между 3D и 2D.
- Управление с клавиатуры и сенсорного экрана.
- Клубок, разлом, Домовой и поиск первой Искры.
- Диалоги и сюжетные флаги.
- Сохранение сюжетных флагов через `localStorage`.
- В версии 0.2 добавлено сохранение координат последней позиции в Яви.
- В версии 0.3 координаты огонька в Нави переносятся обратно в Явь: выход из Нави возвращает героя в соответствующую точку общего пространства (с безопасным ограничением по границам комнаты).

## Как запустить

1. Распакуй архив в отдельную папку.
2. Открой `index.html` в современном браузере. Если браузер блокирует ES-модули при открытии файла напрямую, запусти локальный сервер из папки проекта, например: `python -m http.server 8000`.
3. Открой `http://localhost:8000`.
4. Для сброса прогресса в консоли браузера выполни `iskraReset()` или очисти данные сайта.

Three.js загружается с CDN, поэтому для первого запуска нужен интернет.

## Управление

- **WASD / стрелки** — движение.
- **Мышь** — осмотр в 3D.
- **E** — взаимодействие / продолжить диалог.
- **F** — действие с клубком (когда доступно).
- На телефоне — экранный джойстик и кнопки E/F.

## Художественные ориентиры

Гибридная эстетика: детализированные, но немного игрушечные объёмные декорации; строгие графические силуэты и знаки в 2D; янтарный огонь против холодного бирюзового света; тишина, редкие звуки и ощущение космического фольклора. Не объяснять мифологию сразу — сначала дать игроку почувствовать загадку.

## Принцип разработки

Не переписываем рабочую основу с нуля. Двигаемся короткими итерациями: одна задача — один проверяемый результат. Сначала делаем устойчивым переход между измерениями и сохранение состояния, затем полируем первый уровень, и только после этого строим следующие комнаты.

## Изменения версии 0.3

- Исправлен обратный переход Навь → Явь: сохраняется текущая позиция игрока в 2D непосредственно перед выходом.
- Позиция сохраняется в `localStorage`, поэтому после перезагрузки используется последняя точка в общем пространстве.
