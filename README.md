# ISKRA · ИСКРА

> Космический киберпанк со славянскими мотивами. Puzzle-adventure, в котором ты ходишь между двумя измерениями: **Явью** (3D) и **Навью** (2D).
>
> Работает на **ПК и мобильных устройствах** — мышь/клавиатура и тач-управление с виртуальным джойстиком.

## О чём игра

Станция «Русь-7» дрейфует на орбите. Экипаж исчез. Ты — единственный, кто проснулся. Реальность расколота на две плоскости:

- **Явь** — трёхмерный физический план. Здесь стены, воздух, вакуум. Здесь можно умереть от декомпрессии.
- **Навь** — двумерный духовный план. Здесь видна «изнанка» вещей: скрытые двери, следы экипажа, призраки. Здесь нельзя умереть от вакуума, но можно потерять себя.

Переход между планами — не кнопка, а физическое действие. Первый переход ты совершишь через **клубок** — проводник между мирами.

## Текущий статус · Спринт 1

Реализован **прототип ключевой механики переходов** и **адаптивный ввод (ПК + мобилки)**:

- ✅ Клубок в 3D: подбор, перенос, бросок по дуге
- ✅ Разлом: цель, активация при попадании клубка
- ✅ «Схлопывание» 3D → 2D: камера падает, мир сплющивается, вспышка
- ✅ Навь: вид сверху, тень клубка как точка возврата
- ✅ «Надувание» 2D → 3D: мир вырастает обратно
- ✅ Обратный цикл работает без багов
- ✅ **Виртуальный джойстик** и **тач-кнопки F/E** для мобильных
- ✅ **Мультитач**: джойстик + камера + кнопки одновременно
- ✅ Безопасные зоны (`env(safe-area-inset-*)`), `touch-action: none`, запрет зума/скролла
- ✅ Автоопределение тач-устройства + принудительные режимы `?touch=1` / `?touch=0`

## Управление

### 🖥 ПК (клавиатура + мышь)

| Действие | Клавиша / мышь |
|---|---|
| Движение | `W` `A` `S` `D` / стрелки |
| Камера (в 3D) | зажать ЛКМ + движение мыши |
| Бросить клубок | `F` |
| Действие / переход | `E` |

### 📱 Мобилки (тач)

| Действие | Элемент |
|---|---|
| Движение | Виртуальный джойстик слева-внизу |
| Камера (в 3D) | Тянуть пальцем по свободной части экрана |
| Бросить клубок | Круглая кнопка **F** (жёлтая) справа-внизу |
| Действие / переход | Круглая кнопка **E** (бирюзовая) справа-внизу |

Мобильный UI автоматически скрывается на ПК-устройствах (проверка `(any-pointer: coarse)` + `ontouchstart`).

**Отладка в браузере ПК:**
- `index.html?touch=1` — принудительно включить мобильный UI (можно тестировать мышью)
- `index.html?touch=0` — принудительно выключить
